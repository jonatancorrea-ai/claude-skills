# Crear presentaciones

## Qué hace esta skill

Esta skill convierte información suelta en una presentación clara, ordenada y lista para usar.

Debe ayudarte a pasar de una idea, tema, apunte, guion o texto base a una estructura de diapositivas bien pensada, con títulos claros, bullets cortos y notas útiles para presentar.

## Cuándo debes activarla

Claude debe usar esta skill cuando el usuario:

- Pida una presentación, diapositivas, un slide deck o un material para exponer.
- Quiera transformar ideas, notas, guiones o textos en una presentación.
- Necesite una presentación para enseñar, vender, explicar, lanzar algo o presentar una propuesta.

No uses esta skill si el usuario solo quiere:
- un resumen corto,
- una respuesta rápida,
- o una explicación simple sin formato de presentación.

## Qué debes pedir si falta contexto

Si no está claro, pregunta solo lo esencial:

- tema o idea principal,
- objetivo de la presentación,
- público al que va dirigida,
- duración aproximada,
- estilo visual deseado, si aplica.

## Instrucciones

### 1. Entender el objetivo

Antes de construir la presentación, identifica:
- qué quiere comunicar el usuario,
- a quién va dirigido,
- qué resultado espera lograr.

Si hay ambigüedad, pregunta una sola vez y de forma breve.

### 2. Diseñar la estructura

Propón una estructura lógica y fácil de seguir.

Usa este orden cuando aplique:
- Portada.
- Agenda o índice.
- Desarrollo por bloques.
- Ejemplos o pruebas.
- Resumen.
- Cierre o llamada a la acción.

Ajusta el número de slides al tema, pero evita saturar.

### 3. Escribir el contenido por slide

Para cada diapositiva:
- usa un título corto y claro,
- escribe bullets breves,
- deja una sola idea principal por slide,
- evita párrafos largos,
- añade nota de orador si ayuda.

### 4. Mantener un estilo claro

- Tono cercano, claro y profesional.
- Nada de tecnicismos innecesarios.
- Frases fáciles de escanear.
- Prioriza claridad sobre decoración verbal.

### 5. Revisar antes de entregar

Antes de finalizar, verifica que:
- la secuencia tenga sentido,
- no haya repeticiones,
- no falte una conclusión,
- el mensaje principal se entienda rápido.

## Estilos visuales permitidos

Esta skill puede trabajar con uno de estos dos estilos visuales, según lo que el usuario pida:

### Glassmorphism
Usa este estilo cuando el usuario quiera una presentación moderna, elegante y visual.

Características:
- efecto de cristal esmerilado,
- transparencias suaves,
- bordes redondeados,
- sombras sutiles,
- fondo oscuro o degradado,
- sensación premium y futurista.

### Interactive Deck
Usa este estilo cuando el usuario quiera una presentación con sensación de recorrido o navegación.

Características:
- estructura tipo deck por secciones,
- menú o mapa inicial cuando tenga sentido,
- bloques pensados para moverse entre temas,
- llamadas a la acción visibles,
- sensación dinámica e interactiva.

Si el usuario no especifica el estilo, pregunta:
- “¿Quieres usar Glassmorphism o Interactive Deck?”

## Formato de salida

Devuelve siempre la respuesta en este orden:

1. Lista de slides con sus títulos.
2. Contenido de cada slide.
3. Notas de orador, si aplican.
4. Sugerencias visuales según el estilo elegido.
5. Confirmación final de que la presentación quedó lista para copiar o montar.

## Reglas generales

- Si falta información, pregunta solo lo mínimo necesario.
- No mezcles estilos visuales sin que el usuario lo pida.
- No inventes datos.
- No satures las slides con demasiado texto.
- Prioriza siempre utilidad, claridad y ritmo visual.
